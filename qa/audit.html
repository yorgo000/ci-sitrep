How we vet

The rules the report is built and maintained under. These are not aspirations — they are the working instructions for the daily watch.

  • Information first. Article headlines lead with the finding, never the source name. The source goes in the parenthetical with the date; the full citation is the Source link at the bottom of the article. This is a knowledge base, not a bibliography.
  • Sources live with the content. Every article ends with a Source link to its primary source. Subsections that draw on multiple references carry a Sources line. There are no bibliography dumps — a reader verifies each claim at the point where they read it.
  • Inline links. When prose mentions a source, benchmark, regulation, framework, or product by name, the first mention in each subsection is hyperlinked to its source, so every section is self-contained for a reader who jumps straight to it.
  • Confidence rating. Every article is rated ●●●● to ●○○○ (see above). When in doubt, the lower level is assigned.
  • Link verification. Every new link is verified live before publishing (see Link health above).
  • No silent deletion. When new information supersedes old text, the old text moves to the archive, dated and categorized. The pre-restructure version of the report is preserved in full.
  • The bar for entry. Something is added or changed only if it could change how a firm building critical systems in finance should act.

Coverage — what we track and what we might be missing

Covered: four sections, updated daily — (1) PNL: money, adoption, liability, (2) CIC (Agentic Staff): the agent workforce, (3) Codebase Certification: attesting what is already there, (4) Code Sanitizing Pre-commit: stopping bad code getting in. Focus is critical systems in finance, with the regulatory landscape that governs them (US federal and state, EU, UK, Hong Kong, Singapore, Canada).

Known gaps — things we are watching for that have not arrived yet: the live list is on the report's front page, in What we're watching — the dated events on the horizon and the open questions the report is tracking. It is maintained in the open, in the same file as the report, so it never goes stale.

How sure are we that we are not missing anything? Honestly: not certain, and no honest report can claim otherwise. What we can say is that the daily watch runs against the four sections every morning, the review funnel above shows how much is being looked at, and the known-gaps list is maintained in the open. If a reader finds a material development we have missed, that is a defect in the report — the contact address is ci-sitrep@confluence1.com.
