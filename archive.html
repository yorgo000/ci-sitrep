Subject 1 — Pre-commit scanning

2026-11-10 — CodeMender "not publicly available" (superseded)

  • Old claim (original report, 2026-11-09, Layer C table): "Google DeepMind CodeMender — Fix-only agent — Not publicly available."
  • Superseded by: CodeMender has in fact been in public preview since July 2026 (hundreds of customers, per Google), and the 5 Nov 2026 Security Summit update added vulnerability verification and exploit simulation inside an OS-level sandbox or isolated VM, human-in-the-loop checks for local writes and command execution, and scoped scans. Current entry lives in SYNTHESIZED.md §1.2.3.

2026-11-10 — "No federal model-risk umbrella" as the whole picture (partially superseded)

  • Old claim (original report, 2026-11-09, §1.5.2): "Practical consequence: there is currently no federal model-risk umbrella for AI coding tools — firms must build their own controls."
  • Superseded in part by: OCC Bulletin 2026-54 (4 Nov 2026), a 20-page examiner resource covering exactly the generative and agentic systems SR 26-2 excluded, with sixteen components in six pillars and a four-tier consequence classification. It sets no enforceable standards, so the "no umbrella as law" part still holds — but it no longer holds as examination practice. Current entry lives in SYNTHESIZED.md §1.5.2.

2026-11-11 — "No independent benchmark of agent-time enforcement tools" (partially superseded)

  • Old claim (original report, 2026-11-09, §1.7): "First independent benchmark of agent-time enforcement tools (none exists yet — the category is ~6 months old)."
  • Superseded in part by: CWE-bench v2 (Collinear AI, 3 Nov 2026) — a public, programmatically scored benchmark of 100 tasks (91 CWE classes) for agents finding and fixing security flaws, with 11 models evaluated. It is a yardstick for remediation agents; no agent-time enforcement product has yet been independently measured against it at scale, so the gap is narrowed, not closed. Current entry lives in SYNTHESIZED.md §1.6 and §1.7.

2026-11-12 — "No yardstick for LLM reviewer precision/recall" (partially superseded)

  • Old claim (§1.7): "Precision/recall of LLM reviewers on real PRs at scale." — listed as an open gap with no yardstick.
  • Superseded in part by: SecPRBench (Yang et al., arXiv:2610.33509, 24 Oct 2026) — the first benchmark of agentic pre-merge security review on validated real bug-introducing commits: 265 tasks from nine critical systems, recall 32.5–78.1% across eight frontier models, 68% of misses wrong-mechanism rather than oversights. No commercial review product has yet been independently measured against it at scale, so the gap is narrowed, not closed. Current entry lives in SYNTHESIZED.md §1.6, §1.7 and §2.1.

2026-11-13 — Semgrep Layer A row (expanded)

  • Old text (2026-11-09, §1.2.1 Layer A table): "Semgrep (agent hooks) — Custom-rule SAST in the agent loop; Semgrep Assistant AI triage."
  • Superseded by: Semgrep Agentic AppSec Platform (announced 12 Nov 2026): Guardian fixes issues as agents write, before commit; Mandoline program-analysis engine returns only reachable code paths to agents; Agentic Security Workflows; MCP server; integration with OpenAI Codex Security / Daybreak Defense Factory. Vendor-claimed: agents found 2× more real vulnerabilities than frontier models alone, −65% token costs (method undisclosed). Current entry lives in SYNTHESIZED.md §1.2.

Subject 2 — Code review / scanning (problems already in the codebase)

2026-11-10 — CodeMender "not publicly available" (superseded)

  • Old claim (original report, 2026-11-09, products table): "Google DeepMind CodeMender — Agentic remediation upstreamed to open source — Not a product."
  • Superseded by: CodeMender in public preview since July 2026, with scoped whole-repo / folder / changed-files-only scans, vulnerability verification and exploit simulation in a sandbox or isolated VM, and human-in-the-loop for writes. It is now the leading managed option for exploit-verified fixes (still in preview, no independent accuracy data). Current entry lives in SYNTHESIZED.md §2.3.

  • Old claim (original report, 2026-11-09, §2.4): "No independent accuracy data published yet for any reasoning agent — all vendor claims."
  • Superseded in part by: CWE-bench v2 (3 Nov 2026) gives a public yardstick (leaders ~68% pass@1, even the leader fails 19% of tasks on every attempt). No reasoning-agent product has yet been independently measured against it at scale. Current entry lives in SYNTHESIZED.md §2.4.
